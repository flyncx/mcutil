# mcutil

#### What is this?
A repackaging of Typescript port of [Material Color Utilities](https://github.com/material-foundation/material-color-utilities/). 

Why though? The [original NPM package](https://www.npmjs.com/package/@material/material-color-utilities) is outdated. I want it to be up to date.


#### Should I use this?
Probably not.
